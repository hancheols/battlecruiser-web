계정 삭제 안내

「전투 순양함」(타임스위치)의 계정과 게임 정보를 삭제하는 방법입니다. 웹(game.timeswitch.co.kr)과 안드로이드 앱 모두 같은 계정입니다.

1. 게임 안에서 바로 삭제 (가장 빠른 방법)

  1. 게임에서 함장 프로필을 엽니다.
  2. 설정 > 계정연동 > 계정 삭제를 누릅니다.
  3. 안내 문구를 읽고 입력칸에 삭제를 입력한 뒤 "계정 삭제하기"를 누릅니다.

삭제하면 바로 처리되고 되돌릴 수 없습니다. 삭제 후에는 새 게스트 계정으로 처음부터 시작합니다.

2. 삭제되는 정보

  • 서버에 저장된 계정, 게임 진행 정보(함선, 재화, 클리어 기록, 함장 이름 등)
  • 연결한 구글 계정 정보(구글 계정 식별값, 가린 이메일)
  • 다른 기기에서의 로그인 정보
  • 이 기기에 저장된 게임 진행 정보와 로그인 정보
  • 법령에서 보관을 요구하는 정보(예: 향후 유료 결제 기록)는 해당 기간 동안 분리해 보관한 뒤 파기합니다. 현재는 유료 판매를 하지 않아 해당 정보가 없습니다.

3. 기기를 쓸 수 없을 때: 이메일로 삭제 요청

기기를 분실했거나 앱·웹에 접속할 수 없는 경우 이메일로 요청할 수 있습니다.

  • 받는 주소: hansryan@gmail.com
  • 제목: 계정 삭제 요청
  • 본문에 계정 번호를 적어 주세요. 계정 번호는 게임의 설정 > 정보에 표시됩니다. 계정 번호를 알 수 없는 게스트 계정은 본인을 확인할 수 없어 삭제할 수 없습니다.
  • 접수 후 7일 이내에 처리하고 결과를 이메일로 알려 드립니다.

4. 구글 계정 연결만 해제하고 싶을 때

게임 안에 연결 해제 기능은 아직 없습니다. 위 이메일로 "구글 연결 해제 요청"과 계정 번호를 보내 주세요.

5. 알아두실 점

  • 앱이나 브라우저 데이터를 삭제(제거)하는 것만으로는 서버의 계정이 삭제되지 않습니다. 위 방법으로 삭제해 주세요.
  • 이미 삭제된 계정은 복구할 수 없습니다.
  • 개인정보 처리에 관한 내용은 [개인정보 처리방침](privacy.html)을 확인해 주세요.
